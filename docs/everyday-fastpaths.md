# Everyday deterministic read fast paths (source candidate)

Applies only to standalone EN/NL Everyday turns carrying their original immutable runtime context and an exactly matching already-admitted conversation lease. Generation and authorization state must both match; a freshly sampled device lease or opaque session ID is not authority. Native Workspace and Kids keep their existing paths. Context-bearing turns, ambiguity, compound requests, quoted phrases and unsupported languages continue to the existing narrow reasoner.

Recognized requests: current time/date, current weather from an existing configured Home Assistant weather entity, and exact unambiguous allowlisted single-device on/off status. No write/action shortcuts, new permissions, providers, entity registration or public-weather location disclosure are introduced. Fresh existing tools retain policy checks; cancellation, Kids state and lease currentness are rechecked after awaited reads. Invalid Everyday configuration cannot activate shortcuts. Clock uses the existing configured owner timezone (production Europe/Amsterdam), not the host OS UTC timezone. Categorical route/timing metadata contains no utterance body.

A silent provider-backed candidate probe returned useful clock captions after 3.420 seconds (EN) and 3.942 seconds (NL), compared with archived baseline relay medians 5.141 and 7.211 seconds. These are single candidate samples, not paired repeated confidence estimates. The integrated clock backend took approximately 0.110/0.128 milliseconds. Synthetic output was saved, not played; caption arrival is not audible output. Parent evidence: `/home/timv/.hermes/cache/scratch/homebody-fastpath-performance-v2/performance.json`. The reusable harness is `tools/everyday_fastpath_benchmark.py`.

Modern Live freezes the validated `agent_context` when creating its answer closure. Pipeline captures its context before blocking recognition/prewarming and sends optional `agent_context` on HTTP turns; the host validates it without establishing/upgrading a lease. Old Live/HTTP clients without that context retain the existing narrow reasoner, never the new deterministic shortcut, even if the same device has a newer lease. Stale bound calls fail closed before dispatch; held reads are discarded after lease replacement (including same-generation authorization changes). Existing clock permission is unchanged: conversation mode does not require the Agent-only adult UI unlock. Private/Kids/power/emergency/unavailable guards remain intact. Realtime already uses explicit provider-selected tools rather than this text shortcut and is unchanged; no Realtime latency improvement is claimed.

The timing samples above precede this generation-binding correction and are historical evidence, not a fresh final-candidate provider benchmark. The generation-bound loopback harness is exercised with fixture and real host clocks, no audio/cloud session; end-to-end acoustic and supervised lifecycle acceptance remain outstanding.

Source-only until independently reviewed, combined tests pass, and separately authorized deployment. Fast paths do not remove Live speech planning or connection setup and do not accelerate arbitrary Workspace reasoning.
